## 1. 产品定位与设计原则

### 1.1 一句话定位

一款 PC 单机、像素奇幻冒险风的「持续刷怪 + 刷材料做装备」动作小游戏。玩家从营地出发，经通道进入地区地图，在刷怪点持续战斗、拾取材料，回营地强化/制作装备，逐步挑战更强的怪与 Boss，追求屠龙刀。

### 1.2 核心循环

**营地整备 → 走通道进入地区地图 → 刷怪点刷怪 → 掉材料/装备 → 回营地强化/制作 → 变强 → 去更深的地区/挑战 Boss → 继续刷。**

- 没有「开始一局 / 结束一局」的边界；玩家想刷多久就刷多久，随时可以走回通道回营。
- 营地和战斗地图是两个独立场景，通过手动交互的通道连接。
- 成长是持续的：材料累积、装备强化、任务推进、地区探索。

### 1.3 设计原则

| 原则 | 说明 |
|---|---|
| 持续世界 | 不设开始/结束边界、不做倒计时、不做结束界面；地图持续存在，刷怪点持续重生 |
| 手动战斗 | 玩家自己挥砍、放技能、走位；MVP 不提供自动战斗 |
| 大数字反馈 | 普攻三位数、炎爆四位数；暴击/技能有明显的数字、顿帧、震屏、击退 |
| 爆材料 | 击杀后材料爆开、吸附；稀有材料有光柱与横幅 |
| 持续变强 | 强化/制作/任务/地区推进四条线共同支撑长期目标 |
| 低门槛 | 操作只有移动、普攻、一个技能、冲刺；不需要连招、蓝量、职业理解 |

### 1.4 传奇借鉴边界

只借鉴「力量幻想 + 大数字 + 刷怪爆材料 + 一个招牌技能 + 持续变强」的体验，不照抄传奇的职业、社交、经济、命名与美术。

| 借鉴 | 不借鉴 |
|---|---|
| 大数字、刀刀到肉的打击感 | 三职业（MVP 只做战士） |
| 一个高爆发招牌技能 | PK、交易、组队、行会、排行榜 |
| 刷怪掉材料、Boss 爆装 | 金币、商店、角色等级/经验 |
| 持续刷怪、装备成长 | 传奇专有怪物/技能/装备名（屠龙刀除外） |
| Boss 作为长期挑战目标 | 传奇 MMO 的土黄/暗红/金色 UI |

### 1.5 命名约束

- **只保留「屠龙刀」一个传奇引用**；其余名称必须原创。
- 地图：幽暗林地。
- 怪物：腐化野狗、腐化弓手、岩石傀儡、血牙魔将（Boss）。
- 装备：铁剑、精钢剑、屠龙刀、铁盔、皮甲、血牙战盔、护符。
- 材料：精铁、兽皮、魔力结晶、龙魂。
- 技能：普攻「横扫」；主动「炎爆斩」（暂定名）。
- **龙魂**是 v1.0 对「Boss 稀有材料」的命名，不是 v1.2 原文；文档中保留但标注来源。
- 不使用传奇专有技能、怪物、装备名（屠龙刀除外）。

### 1.6 v1.2 边界、冲突与范围偏差

| v1.2 原文 / 概念 | v1.1 处理 | 说明 |
|---|---|---|
| 约 3 分钟 | **不采用**；本作是持续世界，不设时长目标、不做倒计时、不做结束界面 | 产品已确认忽略该口径；全文仅此一处提及 |
| 在线自动战斗挂机 | MVP **纯手动**；自动作战移到 P2（每日积攒资源，消耗后让武器自动作战） | 属于范围偏差；MVP 验收不再测在线自动战斗 |
| 1 张地图 | 营地 hub（非战斗安全地图）+ 1 张战斗地图「幽暗林地」；MVP 只有 1 张战斗地图 | 多地图与地区材料放附录 F 最终版 |
| 1 个 Boss、3 种怪 | MVP 保留：3 种怪 + 1 个 Boss | Boss 改为固定刷新，不再召唤 |
| 不做复杂剧情 | 新增**最小任务线**：只做目标链，无对话、无过场、无剧情 | 任务只引导、不锁通道；奖励只给材料/装备 |
| 1 张地图内的材料掉落 | 材料分两级 + Boss 材料；不同地图未来可有各自材料 | MVP 只做幽暗林地一套 |
| 装备升级线 | 保留；强化失败降 1 级（+0 保护），保留幸运值 | 比 v1.2 更具体，不冲突 |
| 离线收益 | 保留：8 小时封顶、只产基础材料 | 在线自动战斗不在 MVP |
| 单机、无交易/PK/商业化 | 保留 | 不做多人、交易、行会、内购 |

### 1.7 MVP 范围（P0）

| 模块 | P0 内容 |
|---|---|
| 世界 | 营地 hub（安全地图）+ 幽暗林地（战斗地图）+ 1 条手动通道；营地有锻造台、工作台、装备箱、任务板、篝火 |
| 战斗 | 纯手动：左键/按住或 J「横扫」、Q「炎爆斩」、Space 冲刺；无自动战斗、无自动索敌 |
| 怪物 | 腐化野狗、腐化弓手、岩石傀儡；刷怪点持续重生；同屏上限 60 |
| Boss | 血牙魔将：固定刷新点、双阶段、击杀后 5 分钟重生；无召唤物 |
| 掉落 | 4 种材料；两级材料规则；Boss 掉龙魂/装备；材料自动吸附 |
| 装备 | 4 槽位、5 品阶、+0→+10 强化（失败降 1 级 + 幸运值）、7 个配方、屠龙刀 |
| 任务线 | 7 步最小主线：击杀/收集/制作/强化/击败 Boss/制作屠龙刀；只引导、不锁通道 |
| 存档 | 本地 JSON；材料/装备/幸运值/任务进度/Boss 重生时间；原子写入与损坏恢复 |
| 离线 | 8 小时封顶，只产精铁/兽皮；上线领取 |
| UI | 营地功能台、HUD、技能栏、伤害数字、背包/强化/制作、任务板/追踪、离线、设置、暂停 |
| 平台 | Windows 10/11 x64，1280×720，可全屏 |

### 1.8 明确不做

- 多张战斗地图、地图网络全连通、地区专属材料（放附录 F 最终版）
- 三职业、法师/道士、职业选择、技能树（MVP 只做战士；`class_id` 预留）
- 金币、商店、角色等级/经验、白装/绿装掉落
- PK、交易、组队、行会、排行榜、聊天
- 复杂剧情、对话、过场、NPC 剧情任务
- 每日任务、限时任务、时间盒玩法
- MVP 在线自动战斗（P2）
- Boss 召唤物（MVP 直接固定刷新；召唤物为 P1/P2 预留）
- 最终美术/音频（占位像素资源可接受）
- Steam、成就、云存档、多语言

### 1.9 术语表

| 术语 | 定义 |
|---|---|
| 持续世界 | 没有开始/结束边界；地图持续存在，刷怪点持续重生，玩家随时可回营 |
| 营地 hub | 独立安全地图；有功能台、任务板、通道；无怪物 |
| 战斗地图 | 幽暗林地；有刷怪点、Boss 固定刷新点、回营通道 |
| 刷怪点 | 地图上的固定区域；按配置生成怪物、重生、脱战回点 |
| 通道 | 地图之间的手动传送点；走到附近按 E 交互，确认后切图 |
| 固定刷新 | Boss 在固定点位存在；被击杀后按冷却重生，不靠召唤物 |
| 手动战斗 | 玩家自己按键挥砍/放技能；MVP 无自动战斗 |
| 自动作战 | P2：每日积攒资源，消耗后让武器自动作战；MVP 不实现 |
| 低级材料 | 精铁、兽皮；低级怪只掉低级材料 |
| 高级材料 | 魔力结晶；高级怪高概率掉高级材料，也可能低概率掉低级材料 |
| Boss 材料 | 龙魂；仅 Boss 产出，离线不产出 |
| 龙魂 | v1.0 对「Boss 稀有材料」的具体命名，不是 v1.2 原文 |
| 幸运值 | 同一装备强化失败累积；每失败 +5% 成功率，最高 +25%，成功清零 |
| 任务链 | 只做目标与奖励的最小主线；无剧情对话，不锁地图 |

## 2. 技术基线与工程结构

### 2.1 引擎与语言

| 项目 | 规定 |
|---|---|
| 引擎 | Godot 4.4.x（4.4 或更高的 4.x 稳定版；禁止未经验证的跨小版本升级） |
| 渲染器 | Compatibility，保证集显与老显卡可用 |
| 脚本 | GDScript，全部启用静态类型 |
| 物理 | Godot 2D 物理，物理帧率 60 Hz |
| 第三方插件 | MVP 不引入 |
| 导出 | Windows Desktop，x86_64，嵌入 PCK，单文件 exe |

### 2.2 平台、分辨率与窗口

| 项目 | 规定 |
|---|---|
| 操作系统 | Windows 10 1903+ / Windows 11，x64 |
| 基准分辨率 | 1280×720 |
| 宽高比 | 16:9；`canvas_items + keep`，非 16:9 留黑边 |
| 窗口 | 默认窗口化 1280×720，可缩放；最小 1024×576 |
| 全屏 | 设置中切换，`Alt+Enter` 亦可 |
| 垂直同步 | 开启；目标 60 FPS，最低可接受 30 FPS |
| 字体 | 内置 Noto Sans SC；伤害数字另用加粗显示字体 |
| 输入 | 键鼠；MVP 不支持手柄与改键 |
| 存档路径 | `user://save.json` |

```text
│     ├─ quest_tracker.gd

│     ├─ settings_panel.gd
│     ├─ pause_menu.gd

```

约束：

- 地图是独立场景：`camp_map.tscn` 与 `darkwood_map.tscn`；不得做成单张无缝大世界。
- 地图切换只通过 `MapRouter`，不得在业务代码里直接 `change_scene`。
- 所有数值来自 `data/*.json`；代码内禁止写死伤害、掉落、强化概率。
- 资源 ID 一经发布不得改名，只能新增。
- `class_id` 从第一天存在，MVP 固定为 `warrior`。

### 2.4 Autoload 单例

| 顺序 | 单例 | 职责 | 关键接口 |

| 4 | `GameState` | 材料、装备、幸运值、Boss 重生时间、设置、`class_id` | `add_material()`、`consume_materials()`、`equip()`、`get_player_stats()` |

### 2.8 命名与代码规范

- 资源 ID：小写 `snake_case`，例如 `iron_sword`、`boss_bloodfang`、`loot_dog`。
- 信号：描述已发生的事实，例如 `material_gained`、`quest_completed`、`boss_killed`。
- 公共方法：动词开头，例如 `add_material()`、`travel()`、`claim_quest()`。
- 业务失败返回原因码（附录 B），禁止空值或静默失败。
- 高频对象（敌人、掉落、伤害数字、投射物、VFX）必须池化；禁止每帧 `instantiate()` / `queue_free()`。
- 禁止在 `_process` 中使用 `get_nodes_in_group()`、字符串路径查找、`load()`；引用在 `_ready` 缓存。
- 所有玩家可见文本走 `tr("KEY")`；禁止硬编码中文。
- 数值改动必须同步本文档与 `data/*.json`，保持单一事实来源。

### 2.9 对象池与性能约束

| 对象 | 池上限 | 复用方式 |
|---|---|---|
| 敌人 | 60 | 隐藏、关闭碰撞/AI、重置状态 |
| 掉落物 | 120 | 隐藏、关闭磁吸、重置计时 |
| 投射物 | 40 | 同上 |
| 伤害数字 | 80 | 复用 Label，重置动画 |
| 命中特效 | 24 | 复用 AnimatedSprite2D |

- 同屏敌人超过 60：刷怪点暂停生成，待存活下降后补刷。
- 掉落物超过 120：最早生成的自动入账。
- 伤害数字超过 80：复用最旧的一个。
- 图集按类别合并，减少 draw call；不使用实时阴影与复杂后处理。

### 2.10 本地化与字体

- MVP 仅简体中文；所有文案从 `i18n/zh_CN.csv` 读取，key 用 `UI_` 前缀。
- 字体：Noto Sans SC Regular/Bold；伤害数字使用加粗/描边样式，字号 40/48/64。
- 数字格式化统一：HP/ATK/DEF 整数；百分比 1 位小数；四位数加逗号。

### 2.11 职业预留（MVP 只做战士）

- 存档与技能配置带 `class_id`；MVP 固定 `warrior`；装备暂不区分职业，未来可加职业限制字段。
- 战士使用近战 180° 横扫 + 单体爆发「炎爆斩」；不设计法师/道士内容。
- 未来多职业通过 `classes.json`（P2 新增）扩展，不改现有存档结构。
- MVP 不做职业选择 UI、不做转职、不做多套技能树。

## 3. 世界结构与地图网络

### 3.1 地图网络

MVP 只有两张地图，通过一条通道连接：

```text
┌──────────────┐        通道 A        ┌──────────────────┐
│  营地 hub     │ ←───────────────→ │  幽暗林地（战斗）  │
│  安全、无怪    │   手动 E 交互传送   │  刷怪点 + Boss     │
└──────────────┘                     └──────────────────┘
```

- 营地是独立安全地图，不是战斗地图的一部分。
- 幽暗林地是 MVP 唯一的战斗地图。
- 通道是双向的；玩家走到通道 80px 内按 E，确认后切图。
- 未来多地图是「部分连通」的图，不是全连通；见附录 F，不进入 MVP。

### 3.2 营地 hub

| 项目 | 规定 |
|---|---|
| 地图尺寸 | 1200×800 |
| 玩家出生点 | (600, 600) |
| 安全区 | 全图无怪物、无刷怪点、无战斗 |
| 功能台 | 锻造台 (350,300)、工作台 (850,300)、装备箱 (350,500)、任务板 (600,250)、篝火 (600,400) |
| 通道 | 通往幽暗林地，位置 (600,700) |
| 交互 | 靠近 80px 按 E 打开对应面板/通道确认 |
| BGM | 营地曲 |

- 营地是玩家读档后的默认位置；退出/死亡都回营地。
- 营地内不可攻击、不可放技能、不可使用消耗品（MVP 没有消耗品）。
- 功能台面板是 UI 覆盖层，打开时玩家不能移动；关闭后恢复。
- 任务板只展示主线与领取奖励，不提供对话剧情。

### 3.3 幽暗林地（战斗地图）

| 项目 | 规定 |
|---|---|
| 地图尺寸 | 2400×1800 |
| 入口/回营通道 | 南侧 (1200, 1650) |
| 入口安全区 | 以入口为圆心、半径 200；不刷怪、怪物不进入 |
| 玩家到达点 | (1200, 1600) |
| 刷怪点 | 8 个，见 3.5 |
| Boss 固定刷新点 | 北侧 (1200, 300)，见 3.6 |
| 地图边界 | 树墙/岩壁封闭，玩家不可走出 |
| BGM | 战斗地图曲；Boss 进入战斗切 Boss 曲 |

- 地图没有时间限制；怪物按刷怪点持续重生，没有结束界面。
- 玩家可以一直留在地图里刷怪，也可以随时走回南侧通道回营。
- 地图状态（怪物存活、掉落物）不跨存档保存；读档后重新生成。

### 3.4 通道与手动传送

| 项目 | 规则 |
|---|---|
| 交互 | 玩家进入通道 80px 内，显示「E 前往幽暗林地 / 返回营地」 |
| 确认 | 按 E 打开确认面板；确认后保存 → 0.2 秒淡出 → 加载目标地图 → 0.2 秒淡入 |
| 到达 | 出生在目标地图配置的出生点，面朝地图内部 |
| 取消 | Esc 或「取消」关闭面板，不传送 |
| 保存 | 传送前保存一次；传送后不重复保存 |
| 限制 | 战斗地图内不能直接打开地图菜单；只能走通道 |

- 通道是实体 `Area2D`，不是 UI 按钮；必须走近交互。
- 通道不做全连通：MVP 只有营地 ↔ 幽暗林地；未来地图只在相邻地区之间连通（附录 F）。
- 传送期间玩家输入锁定；加载失败则留在原地图并提示。

### 3.5 刷怪点与重生

| 刷怪点 | 坐标 | 怪物 | 数量 | 重生间隔 |
|---|---|---|---|---|
| SP1 | (500, 1400) | 腐化野狗 | 6 | 12s |
| SP2 | (900, 1100) | 腐化野狗 | 8 | 12s |
| SP3 | (1500, 1100) | 腐化弓手 | 5 | 14s |
| SP4 | (1900, 1400) | 腐化野狗 6 + 弓手 3 | 9 | 14s |
| SP5 | (500, 700) | 岩石傀儡 1 + 野狗 4 | 5 | 15s |
| SP6 | (1900, 700) | 腐化弓手 6 | 6 | 14s |
| SP7 | (700, 400) | 岩石傀儡 2 + 野狗 6 | 8 | 15s |
| SP8 | (1700, 400) | 腐化野狗 8 + 弓手 2 | 10 | 12s |

规则：

- 每个刷怪点有激活半径 1200px：玩家进入半径才开始生成；离开后不再补刷，存活怪脱战回点并消失。
- 每点最多同时存活「配置数量」；死亡后按重生间隔逐个/成批补刷。
- 同屏敌人上限 60；达到上限时所有刷怪点暂停补刷。
- 刷怪点不生成在入口安全区 200px 内；怪物不能进入安全区。
- 怪物脱战距离 900px：离刷怪点超过 900px 或玩家进入营地/安全区，怪物回到刷怪点并重置 HP。
- 刷怪点不保存状态；读档后重新生成。

### 3.6 Boss 固定刷新

| 项目 | 规则 |
|---|---|
| 位置 | 幽暗林地北侧 (1200, 300)，半径 300 的 Boss 区域 |
| 存在方式 | 固定刷新点；Boss 常驻该区域，不靠召唤物 |
| 触发 | 玩家进入 Boss 区域 300px 内，Boss 激活并追击 |
| 重生 | 被击杀后 5 分钟（300 秒）在原点重生；时间记录在存档 |
| 重置 | 玩家死亡、离开地图、或离开 Boss 区域超过 10 秒，Boss 回满血并回原点 |
| 初始状态 | 新档进入地图时 Boss 存在；若存档记录的重生时间未到，则暂时不出现 |
| 无计时 | Boss 战没有倒计时；玩家可以打、可以撤、可以回营补给后再来 |
| 无召唤物 | MVP 不需要召唤物；P1/P2 可再评估召唤物玩法 |

- Boss 区域是圆形竞技场，周围有地形边界；Boss 不离开该区域。
- 玩家可以在 Boss 区域外围观察；进入 300px 才激活。
- Boss 被击杀后，掉落直接生成在地面，玩家拾取；没有结束界面。
- Boss 重生时间 `boss_respawn_at` 保存在存档；读档后按剩余时间决定是否存在。

### 3.7 死亡与复活

| 项目 | 规则 |
|---|---|
| 触发 | 玩家 HP 归零 |
| 表现 | 1.5 秒死亡动画 → 0.3 秒淡出 |
| 复活 | 回营地出生点，HP 全满 |
| 材料 | 已拾取材料全部保留 |
| 装备 | 不掉落、不降级、不损失幸运值 |
| Boss | 若正在打 Boss，Boss 回满血并回原点 |
| 刷怪点 | 怪物脱战重置；玩家回营后地图状态按 3.5 重新生成 |
| 惩罚 | MVP 无额外惩罚（不掉材料、不掉装备、不扣经验） |

- 死亡不是失败，只是回营地重来。
- 玩家可以从营地再走通道回来，继续刷。

### 3.8 读档、地图状态与位置

- 启动/读档后，玩家固定在营地出生点，不恢复上次地图位置。
- 背包、材料、装备、幸运值、任务进度、Boss 重生时间、离线 pending 保存；地图怪物/掉落不保存。
- 读档时若 `boss_respawn_at` 已过，Boss 存在；否则 Boss 不出现，直到时间到。
- 地图切换不保存玩家坐标；每次从通道进入都从配置的出生点开始。

### 3.9 未来地图网络（附录 F，不进入 MVP）

- 最终版是「地区地图 + 部分连通通道」的图：营地 hub 连接起始地区；地区之间只连相邻地图，不做全连通。
- 每张地区地图有自己的刷怪点、怪物池、材料主题、Boss；通道手动交互。
- MVP 只做营地 + 幽暗林地；附录 F 只给图结构和内容规划，不进入本次开发与验收。

## 4. 战斗系统与数值

### 4.1 玩家基础属性

| 属性 | 基础值 | 说明 |
|---|---|---|
| 生命 HP | 1,200 | 死亡回营地，满血复活 |
| 攻击 ATK | 240 | 影响普攻与炎爆斩 |
| 防御 DEF | 0 | 减伤公式见 4.6 |
| 攻击速度 | 1.4 次/秒 | 受装备攻速词条影响，上限 3.0 |
| 暴击率 | 10% | 上限 75% |
| 暴击伤害 | 200% | 固定 |
| 移动速度 | 180 px/s | 上限 260 |
| 拾取半径 | 90 px | 材料自动吸附 |
| 普攻扇形 | 180° | 以鼠标/移动方向为中心 |
| 普攻半径 | 120 px | 近战 |
| 普攻目标数 | 8 | 每次挥砍最多命中 |
| 冲刺距离 | 150 px | 0.18 秒内完成 |
| 冲刺冷却 | 2.0 s | HUD 显示 |
| 冲刺无敌 | 0.15 s | 可穿投射物 |
| 受击无敌 | 0.25 s | 防止连续伤害 |

### 4.2 移动

- 八方向移动，斜向归一化；`CharacterBody2D.move_and_slide()`。
- 玩家与地图边界、障碍碰撞；与敌人不产生物理碰撞（敌人停在攻击距离，避免卡死）。
- 相机 `Camera2D` 跟随玩家，限制在地图边界内，平滑系数 8。
- 玩家可在攻击/施法动作中移动；炎爆斩前 0.2 秒移速减半。
- 冲刺会打断当前攻击后摇，但不重置攻击冷却。

### 4.3 手动普攻「横扫」

**这是 MVP 唯一的普攻方式，只有手动操作。**

| 项目 | 规则 |
|---|---|
| 输入 | 鼠标左键 / J；按住可连续挥砍 |
| 朝向 | 鼠标指向；没有鼠标输入时朝移动方向；键盘 J 朝移动方向 |
| 形态 | 180° 扇形，半径 120px |
| 目标数 | 最多 8 个敌人；每个敌人每次挥砍最多受 1 次伤害 |
| 伤害 | 1.0 × ATK；暴击 10%，暴伤 200% |
| 节奏 | 攻击间隔 = 1 / 攻速；基础 1.4 次/秒 → 0.714 秒 |
| 动作 | 挥砍 0.2 秒；第 0.1 秒命中帧；可移动 |
| 空挥 | 没有敌人也挥砍；不造成伤害，不消耗额外资源 |
| 索敌 | **无自动索敌、无目标锁定**；玩家自己瞄准 |
| 命中 | 命中帧查询半径 120 的圆形，再按 180° 扇形过滤，取最近 8 个 |

- 按住左键时，每 1/攻速 自动重复挥砍（这是「按住连击」，不是自动战斗；朝向仍跟随鼠标）。
- 鼠标位置决定角色朝向；角色不会自动转向最近敌人。
- 攻击可以打空；这是手动战斗的一部分。
- 攻速上限 3.0 次/秒；达到上限后继续堆攻速只影响面板。

### 4.4 炎爆斩（Q）

| 项目 | 规则 |
|---|---|
| 输入 | Q |
| 目标 | 鼠标指向 240px 内最近的敌人；没有目标时提示「没有目标」，不消耗冷却 |
| 主目标伤害 | 3 × ATK，且必定暴击（×2）= **6 × ATK** |
| 基础伤害 | 240 × 6 = **1,440** |
| 溅射 | 主目标周围 80px 内最多 3 个敌人，各受 1 × ATK（不暴击） |
| 冷却 | 8 秒 |
| 前摇 | 0.3 秒；命中帧 0.2 秒；前 0.2 秒移速减半 |
| 表现 | 火焰爆炸、震屏 10px、120ms 顿帧、橙色大数字 |
| 打断 | 玩家被击中不会打断施法；冲刺会取消施法且不返还冷却 |

- 炎爆斩是 MVP 唯一的主动技能；没有蓝量/怒气，只受冷却限制。
- 自动战斗 P2 才会由 AI 释放；MVP 必须玩家手动按 Q。
- 炎爆斩可以打死小怪并溅射到周围；对 Boss 是主要爆发。

### 4.5 冲刺

- 按 Space：沿当前输入方向冲刺 150px，耗时 0.18 秒；没有输入时沿当前朝向。
- 冲刺期间 0.15 秒无敌，可穿过敌方投射物；不造成伤害。
- 冷却 2.0 秒，HUD 显示环形冷却。
- 冲刺会取消炎爆斩前摇；不返还 Q 冷却。
- 冲刺不会穿过地图边界与障碍。

### 4.6 命中检测与伤害公式

**玩家输出伤害**：

```text
raw = ATK × 技能倍率        # 横扫 1.0；炎爆斩 3.0
if 暴击 or 炎爆斩:
    raw = raw × 2.0
final = max(1, round(raw))
```

- 横扫暴击按目标独立判定（10%）。
- 炎爆斩主目标必定暴击；溅射不暴击。
- 小怪与 Boss 的防御按 0 处理；后续如需要，在 `monsters.json` 增加 `def`。
- 伤害数字显示整数；四位数加逗号；暴击金色、炎爆橙色。

**玩家承受伤害**：

```text
mitigation = min(0.60, DEF / (DEF + 1000))
final = max(1, round(怪物攻击力 × (1 - mitigation)))
```

- 受击后 0.25 秒无敌；无敌期间不显示伤害数字。
- 冲刺无敌与受击无敌取剩余时间较长者。
- 玩家 HP 归零 → 3.7 死亡/复活。

### 4.7 敌人 AI

通用状态机：`SPAWN → CHASE → ATTACK → HURT → LEASH → DEAD`。

| 怪物 | HP | ATK | 移速 | 攻击间隔 | 攻击距离 | 索敌 | 行为 |
|---|---|---|---|---|---|---|---|
| 腐化野狗 | 300 | 100 | 120 | 1.2s | 55 | 400 | 直线追击；0.25s 前摇后咬击 |
| 腐化弓手 | 220 | 80 | 80 | 2.0s | 260 | 420 | 保持 220–280px；0.3s 瞄准后射箭，箭速 320 |
| 岩石傀儡 | 2,200 | 180 | 60 | 2.2s | 70 | 350 | 追击；每第 3 次攻击变 0.8s 前摇、半径 80、240 伤害的重击 |

细节：

- **腐化野狗**：命中帧在前摇结束（0.25s）；玩家在前摇结束前离开 80px 可躲开。
- **腐化弓手**：箭矢速度 320 px/s，存活 3 秒；玩家冲刺无敌可穿过。
- **岩石傀儡**：重击有地面预警圈；玩家离开半径 80 免伤。

- 小怪不显示血条；岩石傀儡显示精英血条。

### 5.5 鼠标朝向

- 角色朝向 = 鼠标世界坐标方向；鼠标不动时保持最后朝向。
- 纯键盘 J 攻击时，朝向 = 当前移动方向。
- 攻击/技能的扇形/爆炸均以该朝向为准；没有自动转向最近敌人。
- 手柄/改键不在 MVP；鼠标是主要瞄准设备。

### 5.6 职业：MVP 只做战士

| 项目 | 规则 |
|---|---|
| `class_id` | 固定 `"warrior"`；存档与技能配置带该字段；装备暂不区分职业 |
| 战士定位 | 近战、180° 横扫、单体爆发炎爆斩 |
| 技能 | 横扫（普攻）+ 炎爆斩（Q）；MVP 没有第二个主动技能 |
| 未来职业 | 法师/道士等 P2/P3；通过 `classes.json` 扩展，不改存档结构 |
| 职业选择 | MVP 不做选择 UI、不做转职、不做多套技能树 |

- 装备槽位与属性对所有职业通用；未来职业可加职业限制字段。
- 任务、掉落、地图不按职业区分；MVP 只有战士，不需要分支。

### 5.7 自动作战（P2，不在 MVP）

- MVP 不实现自动战斗/自动索敌。
- P2 设计方向：每日积攒某种资源，消耗后让武器自动作战；资源名称、上限、消耗规则待定。
- 自动作战不影响 MVP 的输入、UI、存档与验收；相关字段/占位在 P2 再定。

### 5.8 技能与操作验收

- 按住左键可连续挥砍；松开停止；攻速与面板一致。
- Q 在 240px 内有目标时释放并造成 6× ATK；无目标不消耗冷却。
- 鼠标朝向正确；攻击扇形随鼠标转动。
- 冲刺可穿投射物、不可穿墙；CD 正确。
- MVP 只有手动操作。

## 7. 掉落与材料分级

### 7.1 材料分级

| 等级 | 材料 | 来源 | 用途 |
|---|---|---|---|
| 低级 | 精铁、兽皮 | 低级怪（野狗/弓手）、高级怪低概率 | 强化、基础制作 |
| 高级 | 魔力结晶 | 高级怪（傀儡）高概率、Boss | 高级制作、强化 |
| Boss | 龙魂 | 仅 Boss | 屠龙刀 |

- **低级怪只掉低级材料**；野狗/弓手不掉魔力结晶/龙魂。
- **高级怪掉高级材料（高概率）+ 低级材料（低概率）**；傀儡的低级材料掉率低于野狗/弓手的主掉落率。
- Boss 掉龙魂 + 高级/低级材料 + 装备。
- 龙魂是 v1.0 命名；v1.2 只写「Boss 稀有材料」。

### 7.2 掉落规则

1. 每次击杀独立 roll；同一条目可额外 roll（如「+1」）。
2. 低级怪只读取低级材料条目；高级怪读取高级 + 低级条目；Boss 读取 Boss 表。
3. 材料掉落实体自动吸附；装备直接进背包/待领取。
4. 没有金币、没有白装/绿装掉落；普通怪只掉材料。
5. 不同地图未来可有各自的低级/高级材料；MVP 只有幽暗林地一套。

## 8. 装备与成长

### 8.1 槽位与品阶

| 槽位 | id | 说明 |
|---|---|---|
| 武器 | `weapon` | 攻击力为主 |
| 头盔 | `helmet` | 生命/防御 |
| 护甲 | `armor` | 生命/防御 |
| 饰品 | `accessory` | 暴击/攻速 |

| 品阶 | id | 颜色 | 词条数 | 获取 |
|---|---|---|---|---|
| 普通 | `common` | 白 | 0 | 制作随机 |
| 精良 | `green` | 绿 | 0 | 制作随机 |
| 稀有 | `blue` | 蓝 | 1 | 制作随机 |
| 史诗 | `purple` | 紫 | 2 | 制作随机 / Boss 15% |
| 传说 | `legendary` | 橙 | 0（固定） | 屠龙刀配方 / Boss 3% |

- 普通配方最高出史诗；不出传说。
- 传说只有屠龙刀；血牙战盔固定史诗。

### 8.2 属性模型

| 属性 | 基础值 | 装备来源 | 最终公式 | 上限 |
|---|---|---|---|---|
| 生命 HP | 1,200 | 主属性 HP、词条 HP | 1,200 + Σ装备 HP | 无 |
| 攻击 ATK | 240 | 主属性 ATK、词条 ATK | 240 + Σ装备 ATK | 无 |
| 防御 DEF | 0 | 主属性 DEF、词条 DEF | 0 + Σ装备 DEF | 减伤上限 60% |
| 攻击速度 | 1.4 次/秒 | 主属性攻速、词条攻速 % | 1.4 × (1 + Σ攻速 %) | 3.0 次/秒 |
| 暴击率 | 10% | 主属性暴击、词条暴击 % | 10% + Σ暴击 % | 75% |
| 暴击伤害 | 200% | 固定 | 200% | 无 |
| 移动速度 | 180 px/s | 词条移速 % | 180 × (1 + Σ移速 %) | 260 px/s |

**叠加顺序**：

1. 装备主属性 = 原型主属性 × 品质倍率（固定品质按 1.0）×（1 + 0.08 × 强化等级）。
2. 固定品质装备的百分比主属性（屠龙刀暴击/攻速、血牙战盔暴击）不乘强化倍率；随机品质装备（含护符）的百分比主属性正常乘。
3. 词条是固定值，不乘品质/强化。
4. 四件装备的扁平属性分别求和，再加基础值。
5. 百分比属性相加，不连乘。
6. 防御减伤 = `DEF/(DEF+1000)`，上限 60%。
7. 内部浮点；UI 显示 HP/ATK/DEF 四舍五入，百分比 1 位小数。

**品质倍率**：普通 1.00 / 精良 1.15 / 稀有 1.30 / 史诗 1.50 / 传说 1.80（仅随机品质原型；固定传说按 1.0）。

**强化倍率**：`1 + 0.08 × 等级`，+10 为 1.80；作用于全部主属性，固定品质的百分比主属性除外。

### 8.3 装备实例

```json
{
  "uid": "it_1761700000_4821",
  "archetype": "iron_sword",
  "quality": "blue",
  "level": 3,
  "affixes": [{ "stat": "atk", "value": 50 }],
  "luck": 2
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `uid` | String | 唯一 id；`it_<unix秒>_<随机>` |
| `archetype` | String | 原型 id |
| `quality` | String | 五品阶 |
| `level` | int | 0–10 |
| `affixes` | Array | 蓝 1、紫 2；固定传说/史诗无随机词条 |
| `luck` | int | 强化幸运值 0–5；失败 +1，成功清零 |

- `luck` 跟着装备走，跨等级保留；不是角色全局。
- 装备对象只通过 GameState 修改；UI 读副本。

### 8.4 强化线（失败降 1 级 + 幸运值）

| 项目 | 规则 |
|---|---|
| 等级范围 | +0 至 +10 |
| 成功判定 | 每次点击独立 roll |
| 失败 | 扣除材料，等级 **-1**（最低 +0）；不破碎 |
| 幸运值 | 每次失败 `luck +1`（0–5）；下次成功率 +5 个百分点/层 |
| 幸运上限 | +25 个百分点 |
| 幸运清零 | 强化成功清零 |
| 存储 | 装备实例 `luck` |
| 适用范围 | 所有可强化装备（含武器；武器是主要场景） |
| 满级 | +10 后禁用 |
| 保存 | 每次强化后立即保存，禁止回档刷结果 |

**成功率表**：

| 目标等级 | 基础成功率 | 幸运满后 | 失败结果 |
|---|---|---|---|
| +1 | 100% | 100% | 不会失败 |
| +2 | 100% | 100% | 不会失败 |
| +3 | 95% | 100% | 扣材料，等级 +1 |
| +4 | 90% | 100% | 扣材料，等级 +2 |
| +5 | 85% | 100% | 扣材料，等级 +3 |
| +6 | 80% | 100% | 扣材料，等级 +4 |
| +7 | 70% | 95% | 扣材料，等级 +5 |
| +8 | 60% | 85% | 扣材料，等级 +6 |
| +9 | 50% | 75% | 扣材料，等级 +7 |
| +10 | 40% | 65% | 扣材料，等级 +8 |

> 失败结果按「当前等级 -1」计算；例如 +4 冲 +5 失败 → 回到 +3。

**流程**：

1. 选择装备（已穿戴或背包）。
2. 面板显示当前等级、目标等级、基础成功率、幸运加成、总成功率、材料消耗、升级后属性预览、失败降级警告。
3. 点击强化 → 确认（所有强化都提示「失败会降 1 级」）→ 校验材料 → 扣材料 → roll。
4. 成功：等级 +1，`luck = 0`，刷新属性，立即保存。
5. 失败：等级 -1（最低 +0），`luck = min(5, luck+1)`，播放失败动画，立即保存；材料不返还。
6. 等级最低为 +0；当前成功率表下 +1/+2 为 100%，不会出现掉到 +0 的情况。

**公式**：

```text
success_rate = min(1.0, base_rate[target] + 0.05 × luck)
luck = clamp(luck, 0, 5)
```

- 面板显示的总成功率必须与实际 roll 使用同一函数。
- 幸运值达到 5 后，失败不再增加，但仍降 1 级；下次仍按 +25% 加成计算。

| 背包满 | `INVENTORY_FULL` | 禁止制作/卸下 |
| 配方不存在 | `RECIPE_NOT_FOUND` | 按钮禁用 |
| 存档失败 | `SAVE_WRITE_FAILED` | 保留内存状态；提示 |

## 9. 任务线

### 9.1 定位

- 任务线是**目标链**，不是剧情线：没有对话、过场、NPC 剧情、分支选择。
- 只做一件事：告诉玩家「接下来去哪、打什么、做什么」，并给阶段奖励。
- **不锁地图通道、不锁 Boss、不锁功能**；玩家可以完全无视任务自由刷。
- 没有每日任务、限时任务、时间盒；所有目标都是计数/里程碑。

### 9.2 数据驱动

`quests.json` 每条任务：

```json
{
  "id": "q_first_hunt",
  "title": "初次狩猎",
  "desc": "在幽暗林地击杀 20 只低级怪。",
  "objectives": [
    { "type": "kill_monster_tier", "tier": "low", "count": 20 }
  ],
  "rewards": { "iron": 50, "hide": 30 },
  "next": "q_first_equipment"
}
```

| 字段 | 说明 |
|---|---|
| `id` | 唯一任务 id |
| `title` | 一句话标题 |
| `desc` | 一句话描述；无剧情 |
| `objectives` | 目标列表；全部完成才可领奖 |
| `rewards` | 材料/装备；不给龙魂/屠龙刀/金币 |
| `next` | 下一任务 id；最后一条为 null |

### 9.3 目标类型

| 类型 | 参数 | 事件 |
|---|---|---|
| `kill_monster` | monster_id, count | 击杀指定怪 |
| `kill_monster_tier` | tier(low/high), count | 击杀某等级怪 |
| `collect_material` | material_id, count | 累计获得材料 |
| `craft_item` | count, archetype（可选） | 制作装备（可按原型过滤） |
| `upgrade_to` | level | 任一装备强化到 +N |
| `defeat_boss` | boss_id | 击败 Boss |
| `enter_map` | map_id | 首次进入地图 |
| `equip_quality` | quality | 穿戴某品阶装备 |

- 事件由 `QuestManager.on_event(type, payload)` 接收；不轮询背包。
- 进度只增不减；材料被消耗后不回退「累计获得」进度。
- 任务完成不自动发奖；玩家在任务板/HUD 点击「领取」。

## 10. 离线收益与自动作战

### 10.1 离线收益

只有游戏完全退出后才累计离线时间；游戏开着（营地/地图）不算离线。

| 项目 | 规则 |
|---|---|
| 产出 | 仅精铁、兽皮 |
| 精铁速率 | 3 / 分钟 |
| 兽皮速率 | 2 / 分钟 |
| 单次上限 | 8 小时（28,800 秒） |
| 结晶/龙魂/装备 | 0 |
| 计算 | 按秒计算，向下取整 |
| 领取 | 下次启动「继续」时领取 |
| 弹窗阈值 | ≥60 秒弹窗；<60 秒自动入账 |

```text
raw_seconds = max(0, now_unix - last_seen_at)
seconds = min(raw_seconds, 28800)
iron = floor(seconds × 3 / 60)
hide = floor(seconds × 2 / 60)
```

示例：

| 离线时长 | 精铁 | 兽皮 |
|---|---|---|
| 1 小时 | 180 | 120 |
| 2 小时 | 360 | 240 |
| 7 小时 59 分 | 1,437 | 958 |
| 8 小时 | 1,440 | 960 |
| 10 小时 | 1,440（封顶） | 960（封顶） |

- 离线不产魔力结晶、龙魂、装备；不跳过 Boss/屠龙刀追求。
- 离线收益不消耗资源，不与在线产出叠加计算。

### 10.2 离线收益计算与领取

**启动**：

1. 读档得到 `last_seen_at` 与 `offline_pending`。
2. 若 `now >= last_seen_at`：`raw = now - last_seen_at`；`last_seen_at = now`。
3. 若 `now < last_seen_at`（回拨）：`raw = 0`，**不修改** `last_seen_at`。
4. `total_seconds = min(28800, pending.seconds + min(raw, 28800))`。
5. 按总秒数重算 iron/hide，写回 pending。
6. 立即保存。

**继续**：

- `pending.seconds >= 60`：弹窗显示时长、精铁、兽皮；点击「领取」→ 入账 → pending 清零 → 保存 → 进营地。
- `<60`：不弹窗，自动入账（可能为 0），保存后进营地。
- 弹窗不可 Esc 关闭；必须领取。
- 新游戏丢弃旧 pending。

**防重复**：启动即更新 `last_seen_at` 并保存；pending 只在领取时清零；未领取退出，下次累加但总时长封顶 8 小时。

### 10.3 时间异常

| 场景 | 处理 |
|---|---|
| 时间回拨 | 本次 0 收益；不修改 `last_seen_at` |
| 时间前跳 30 天 | 8 小时封顶 |
| 多次启动不领取 | pending 累加，总时长封顶 8 小时 |
| 跨版本 | 先迁移存档，再按当前速率计算 |
| `last_seen_at` 缺失/非法 | 视为 0，本次不发；记录日志 |
| `last_seen_at` 为未来 | 视为回拨，本次 0 |

### 10.4 在线自动作战（P2，不在 MVP）

- v1.2 的「在线自动战斗挂机」在 MVP 中**不实现**；MVP 纯手动。
- P2 方向：每日积攒某种资源，消耗后让武器自动作战；资源名称、上限、消耗规则待定。
- 自动作战不进入 MVP 的输入、UI、存档、验收；不设计具体数值。
- 离线收益与自动作战是两件事：离线不模拟战斗，只按时间给基础材料。

### 10.5 验收

- 离线 8 小时领取 1,440 精铁 + 960 兽皮；不产结晶/龙魂/装备。
- 离线 7 小时 59 分领取 1,437 精铁 + 958 兽皮。
- 离线 30 秒自动入账 1 精铁 + 1 兽皮，不弹窗。
- 回拨后启动 0 收益；材料不减少。
- 未领取退出后仍可领取，总时长不超过 8 小时。
- MVP 没有任何自动战斗/自动索敌入口。

## 11. 存档系统

### 11.1 存档示例

```json
{
  "version": 1,
  "class_id": "warrior",
  "created_at": 1761700000,
  "last_saved_at": 1761703600,
  "last_seen_at": 1761703600,
  "player": {
    "materials": { "iron": 1240, "hide": 860, "essence": 12, "soul": 1 },
    "equipped": {
      "weapon": "it_1761700000_4821",
      "helmet": null,
      "armor": null,
      "accessory": null
    },
    "inventory": [
      {
        "uid": "it_1761700000_4821",
        "archetype": "iron_sword",
        "quality": "blue",
        "level": 3,
        "affixes": [{ "stat": "atk", "value": 50 }],
        "luck": 2
      }
    ]
  },
  "progress": {
    "quest": {
      "active_id": "q_first_hunt",
      "progress": { "kill_monster_tier:low": 12 },
      "completed": []
    },
    "boss_respawn_at": 0,
    "total_kills": 86,
    "boss_kills": 0,
    "unlocked_maps": ["camp", "darkwood"]
  },
  "offline_pending": { "seconds": 0, "iron": 0, "hide": 0 },
  "settings": {
    "master_volume": 0.8,
    "music_volume": 0.7,
    "sfx_volume": 0.9,
    "fullscreen": false,
    "screen_shake": true
  },
  "flags": { "tutorial_done": false }
}
```

- `inventory` 保存全部装备实例（含已穿戴），`equipped` 只存 uid 引用；UI 过滤已穿戴。
- 装备实例含 `luck`；不保存地图位置、怪物/掉落状态。
- `boss_respawn_at` 为 Unix 秒；0 表示 Boss 当前存在。

### 11.2 字段说明

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `version` | int | ≥1 | 存档版本 |
| `class_id` | String | `warrior` | MVP 固定 |
| `created_at` | int | Unix 秒 | 新档时间 |
| `last_saved_at` | int | Unix 秒 | 最近保存 |
| `last_seen_at` | int | Unix 秒 | 离线计算基准 |
| `player.materials` | object | 4 键非负 | 精铁/兽皮/结晶/龙魂 |
| `player.equipped` | object | 4 槽位 | uid 或 null |
| `player.inventory` | array | ≤44（未穿戴≤40+已穿戴≤4） | 含已穿戴 |
| `progress.quest` | object | — | 当前任务/进度/完成 |
| `progress.boss_respawn_at` | int | ≥0 | 0=存在；否则重生时间 |
| `progress.total_kills` | int | ≥0 | 累计击杀 |
| `progress.boss_kills` | int | ≥0 | Boss 击杀数 |
| `progress.unlocked_maps` | array | 含 camp/darkwood | 预留 |
| `offline_pending` | object | seconds 0–28800 | 未领取离线 |
| `settings` | object | 音量 0–1 | 设置 |
| `flags` | object | — | 标记 |

### 11.3 保存时机

| 时机 | 说明 |
|---|---|
| 启动完成离线计算 | 写 `last_seen_at`/pending |
| 地图内每 15 秒 | 自动保存 |
| 营地每 30 秒 | 自动保存 |
| 通道传送前 | 保存一次 |
| 强化/制作/穿戴/丢弃/卸下 | 成功后立即保存 |
| 任务领取 | 立即保存 |
| Boss 击杀/重置 | 保存 `boss_respawn_at` |
| 离线领取 | 清空 pending 并保存 |
| 设置变更 | 防抖 0.5 秒保存 |
| 暂停/窗口关闭/退出 | 保存后退出 |

- 强化/制作后立即保存，防止回档刷结果。
- 地图怪物/掉落不保存；读档重新生成。

### 11.4 原子写入

```text
1. 序列化 → JSON 字符串
2. 写 user://save.tmp，flush，close
3. save.json 存在：删旧 bak → rename(save.json → save.bak)
4. rename(save.tmp → save.json)
5. 任一步失败：保留旧档，删 tmp，提示错误，内存不回滚
```

- 保存失败不开始新地图传送；提示玩家重试。
- 保存成功更新 `last_saved_at` 与 `last_seen_at`。

### 11.5 版本迁移

- 当前 `version = 1`。
- `version > 1`：不加载，备份为 `save.future.<时间戳>`，提示更新游戏。
- `version < 1`：视为无档。
- 未来多地图 v2：新增 `unlocked_maps`/`cleared_maps`/地区材料；旧档默认 camp/darkwood。
- 迁移前备份原档；失败恢复。

### 11.6 损坏恢复

| 情况 | 处理 |
|---|---|
| JSON 解析失败 | 读 `save.bak` |
| 字段缺失/类型错误/负数/等级越界/luck 越界 | 视为损坏，读 bak |
| uid 重复/引用不存在 | 视为损坏，读 bak |
| inventory 未穿戴 >40 或数组 >44 | 截断多余并记录 |
| bak 也损坏 | 新档；损坏文件保留 `save.corrupt.<时间戳>` |
| 恢复成功 | bak 覆盖 save.json；提示 |

### 11.7 路径与多实例

- `user://save.json`、`save.bak`、`save.tmp`、`save.corrupt.<时间戳>`。
- Windows：`%APPDATA%\Godot\app_userdata\Legend\`。
- 只写 `user://`，不写安装目录/注册表。
- MVP 不支持多开；后保存覆盖前者，风险记录于 16.2。
- 写入失败：提示磁盘/权限；连续失败暂停自动保存；退出前二次确认。

### 11.8 安全边界

- 单机、无联网、无账号；不承诺防作弊。
- 下限保护：材料非负、等级 0–10、luck 0–5、背包 40、离线 8 小时。
- 玩家可直接编辑 JSON；MVP 不加密、不检测。

## 14. 非功能需求

### 14.1 性能

| 场景 | 目标 |
|---|---|
| 战斗地图（60 敌 + 120 掉落 + 80 伤害数字） | 1920×1080 下 ≥60 FPS；最低 ≥30 FPS |
| 营地 | ≥60 FPS |
| 同屏敌人 | 上限 60；超过暂停补刷 |
| 同屏掉落 | 上限 120；超过自动入账 |
| 同屏伤害数字 | 上限 80；复用最旧 |
| 物理查询 | 每次攻击一次扇形查询；禁止每帧全场扫描 |
| 内存 | 连续游玩 30 分钟增长 <10% |
| GC | 高频对象全部池化；避免每帧分配 |

- 测试硬件：GTX 1050 / Intel Iris Xe / 16GB / 1080p。
- 帧率 <30 FPS 时优先降 VFX/伤害数字，不降敌人 AI。
- 掉帧记录场景、敌人数、帧率。

### 14.2 加载与存档

| 项目 | 目标 |
|---|---|
| 启动到主菜单 | ≤3 秒（SSD） |
| 地图切换（通道） | ≤0.5 秒 |
| 单次保存 | ≤50 ms |
| 离线计算 | ≤10 ms |
| 配置加载校验 | ≤100 ms |

- 地图切换黑屏 + 淡入淡出；不显示未初始化 UI。
- 保存同步写入；超过 50ms 记录日志并优化 JSON。

### 14.3 稳定性

- 连续游玩 30 分钟不崩溃、不卡死、内存不持续上涨。
- 窗口关闭/Alt+F4 触发保存后退出。
- 存档损坏可恢复 bak；恢复失败可新档且不崩溃。
- 保存失败不崩溃、不丢内存状态；提示玩家。
- 材料不为负、等级 0–10、luck 0–5、背包 40。

- `questcomplete`：完成当前任务
- `bossreset`：重置 Boss 重生时间

发布构建关闭控制台。日志写 `user://logs/game.log`，上限 5MB。

### 14.7 安全与公平

- 单机、无联网、无账号；不承诺防作弊。
- 只做下限保护（见 11.8）。
- 离线用本地时间；回拨 0 收益，前跳 8 小时封顶。
- 不收集用户数据；不发起网络请求。

### 14.8 可访问性

- P1：屏幕震动开关、伤害数字大小/关闭、低血量提示开关。
- 品阶不只靠颜色：边框+文字。
- Boss 冲锋/地裂必须有形状与动画预警，不只靠音效。
- 鼠标瞄准为主；纯键盘 J 可攻击，但 Q 仍需要鼠标指向。

## 15. 验收标准

### 15.1 功能验收（TC-01 ~ TC-18）

**TC-01 营地、通道与地图切换**

- Given：全新存档。
- When：启动 → 新游戏 → 营地 → 走到通道 → E → 确认前往。
- Then：保存成功；0.2 秒淡出、加载幽暗林地、0.2 秒淡入；玩家出生在 (1200,1600)；没有倒计时、没有结束界面；从回营通道可返回营地。

**TC-02 刷怪点与重生**

- Given：玩家进入幽暗林地，靠近 SP1/SP3。
- When：等待刷怪与击杀。
- Then：SP1 生成 6 只野狗、SP3 生成 5 只弓手；死亡后按 12/14 秒补刷；同屏不超过 60；玩家离开 1200px 后停止补刷、存活怪脱战回点；入口 200px 安全区不刷怪。

**TC-03 手动战斗**

- Given：玩家在战斗中，鼠标指向敌人。
- When：按住左键 / J；按 Q；按 Space。
- Then：横扫 180°、120px、最多 8 目标，单次 240、暴击 480；按住按 1.4 次/秒重复；角色不自动转向最近敌人；Q 对 240px 内目标造成 1,440 并进 CD 8 秒；无目标时提示「没有目标」且不进 CD；冲刺 150px/CD 2 秒/0.15 秒无敌。

**TC-04 材料分级**

- Given：分别击杀野狗、弓手、傀儡。
- Then：野狗只掉精铁/兽皮；弓手只掉兽皮/精铁；傀儡 80% 掉魔力结晶，并以 35%/30% 掉精铁/兽皮（低于低级怪主掉落 100%）；低级怪不掉结晶/龙魂。

**TC-05 强化失败降级与幸运值**

- Given：铁剑 +3，luck 0，材料充足；固定种子分别复现成功与失败。
- Then（成功）：+4，luck 0，扣 58/33/1，属性按 +4 重算。
- Then（失败）：回到 +2，luck 1，扣 58/33/1；下一次 +2 冲 +3 的成本 40/22/1，总成功率 95% + 5% = 100%。
- Then（低等级失败）：另起一把铁剑 +2、luck 0，冲 +3 失败 → 回到 +1，luck 1，材料扣除。
- Then（满级）：+10 后按钮禁用。
- Then（保底上限）：luck 5 时总成功率 = 基础 +25%，失败仍降 1 级。

**TC-06 制作**

- Given：材料 精铁 100 / 兽皮 100 / 结晶 10，背包有空位。
- When：制作铁剑。
- Then：扣 40/10；产出白/绿/蓝/紫按 45/33/16/6；+0、luck 0；蓝 1 词条、紫 2 词条；进背包；成功后保存。

**TC-07 成长与「一刀 999」**

- Given：裸装、绿装 +2、蓝精钢剑 +5、紫精钢剑 +10 四套配置。
- When：打同一只野狗/傀儡/Boss。
- Then：普攻 240/347/495/618；暴击 480/693/990/1,236；炎爆 1,440/2,080/2,969/3,708；Boss 理论 TTK 108/75/52/40 秒；数字显示四位数加逗号、暴击金色、炎爆橙色。

**TC-08 Boss 固定刷新**

- Given：幽暗林地 Boss 存在。
- When：进入 Boss 区域 300px。
- Then：Boss 激活；无倒计时、无召唤物；击杀后掉龙魂/结晶/铁/皮/装备；`boss_respawn_at` 写为当前 +300 秒；300 秒后原点重生；玩家死亡/离开 10 秒则回满血回原点。

**TC-09 死亡与复活**

- Given：玩家 HP 归零。
- When：死亡动画结束。
- Then：1.5 秒演出 → 回营地出生点、满血；材料/装备/luck 保留；Boss 重置；没有掉落惩罚；可从通道再进地图。

**TC-10 任务线**

- Given：新档任务「初次狩猎」。
- When：击杀 20 只低级怪 → 打开任务板 → 领取。
- Then：进度 20/20；领取后精铁 +50、兽皮 +30；自动接「第一件装备」；重复点击不重复发奖；任务未完成时通道/Boss/制作仍可用。

**TC-11 退出与读档**

- Given：已获得材料、装备、luck、任务进度、Boss 重生时间。
- When：退出到主菜单/关闭窗口 → 重新启动 → 继续。
- Then：读档在营地；材料/装备/luck/任务进度/Boss 重生时间保留；地图怪物/掉落重新生成；玩家位置不恢复。

**TC-12 离线收益**

- Given：`last_seen_at = T`，关闭游戏 2 小时。
- When：启动 → 继续。
- Then：弹窗「2 小时 00 分」「精铁 +360」「兽皮 +240」；领取后入账；pending 清零；再次启动不重复。
- Then（短离线）：30 秒 → 不弹窗，自动入账 1 精铁 + 1 兽皮。

**TC-13 离线不跳过 Boss/极品**

- Given：离线 8 小时并领取。
- Then：只加 1,440 精铁 + 960 兽皮；不加结晶/龙魂/装备；Boss 仍需主动打，屠龙刀仍需 3 龙魂制作或 Boss 3% 直掉。

**TC-14 通道交互**

- Given：营地通道/回营通道。
- When：E → 确认；再次 E → 取消。
- Then：确认后保存、淡出/加载、到达目标出生点；取消不传送；传送失败留在原地图并提示；通道不锁、不需要任务。

**TC-15 打击感**

- Given：普攻命中/暴击/炎爆。
- Then：50/90/120ms 顿帧；4/6/10px 震屏；20/40/80px 击退；受击闪白；伤害数字上浮；连斩计数；Boss 击杀慢动作；设置可关闭震屏（P1）。

**TC-16 爆材料与爆装**

- Given：击杀普通怪/Boss。
- Then：材料爆开吸附；结晶/龙魂光柱与横幅；Boss 装备紫色/橙色光柱；Boss 击杀掉落飞散；没有白装/金币。

**TC-17 职业预留**

- Given：新档/读档。
- Then：`class_id = "warrior"`；没有职业选择 UI；战士技能只有横扫+炎爆；未来职业字段不破坏存档。

**TC-18 MVP 纯手动**

- Given：MVP 任意界面。
- Then：不存在自动战斗/自动索敌按钮或开关；自动作战只在文档 P2 描述中出现；离线收益独立存在。

### 16.4 变更流程

1. 数值改动先改 `data/*.json`，再同步本文档；不一致以配置表为准并开缺陷。
2. 配置字段增删必须更新附录 A，并评估存档迁移。
3. 成功率/降级/幸运值/离线封顶/背包容量属于规则级变更，更新版本号与变更记录。
4. 新增怪/装备/配方属于内容级变更，更新对应章节与验收。
5. 多地图、多职业、自动作战属于范围级变更，单独评审，不塞进 MVP。

### 附录 B 错误码与文案

| 原因码 | 类型 | 触发 | 文案 key |
|---|---|---|---|
| `UPGRADE_NO_MATERIALS` | 业务拒绝 | 强化材料不足 | `UI_MATERIAL_SHORT` |
| `UPGRADE_MAX_LEVEL` | 业务拒绝 | 已 +10 | `UI_UPGRADE_MAX` |
| `UPGRADE_FAILED` | 业务结果 | roll 失败 | `UI_UPGRADE_FAILED` |
| `ITEM_NOT_FOUND` | 错误 | uid 不存在 | `UI_ITEM_NOT_FOUND` |
| `EQUIP_WRONG_SLOT` | 业务拒绝 | 槽位不符 | `UI_WRONG_SLOT` |
| `INVENTORY_FULL` | 业务拒绝 | 背包满 | `UI_INVENTORY_FULL` |
| `CRAFT_NO_MATERIALS` | 业务拒绝 | 制作材料不足 | `UI_MATERIAL_SHORT` |
| `RECIPE_NOT_FOUND` | 错误 | 配方不存在 | `UI_ERROR_GENERIC` |
| `SAVE_WRITE_FAILED` | 错误 | 磁盘/权限 | `UI_SAVE_FAILED` |
| `SAVE_CORRUPT` | 错误 | 存档损坏 | `UI_SAVE_CORRUPT` |
| `SAVE_FUTURE_VERSION` | 错误 | 存档版本更高 | `UI_SAVE_FUTURE` |
| `OFFLINE_NONE` | 业务结果 | 离线 <60 秒 | 无（自动入账） |
| `OFFLINE_ALREADY_CLAIMED` | 业务拒绝 | 重复领取 | `UI_ERROR_GENERIC` |
| `QUEST_NOT_FOUND` | 错误 | 任务 id 不存在 | `UI_ERROR_GENERIC` |
| `QUEST_NOT_COMPLETE` | 业务拒绝 | 目标未完成 | `UI_QUEST_NOT_READY` |
| `QUEST_ALREADY_CLAIMED` | 业务拒绝 | 重复领取 | `UI_ERROR_GENERIC` |
| `PASSAGE_BLOCKED` | 业务拒绝 | 传送条件不满足 | `UI_PASSAGE_BLOCKED` |
| `MAP_LOAD_FAILED` | 错误 | 地图加载失败 | `UI_MAP_LOAD_FAILED` |
| `BOSS_NOT_READY` | 业务结果 | Boss 重生未到 | 无（不显示 Boss） |
| `CONFIG_INVALID` | 错误 | 配置校验失败 | `UI_CONFIG_INVALID` |
| `INPUT_BLOCKED` | 业务拒绝 | 模态/传送中 | 无 |

规则：

- 业务拒绝返回 `{ok:false, reason}`，不抛异常。
- 系统错误记录日志；UI 显示通用文案 + 重试。
- `UPGRADE_FAILED` 是正常业务结果，不计错误日志。

#### F.3 地图数量与内容量

- 最终版 5–6 张战斗地图 + 营地 hub；每张图 3–5 种怪、1 个 Boss、独立掉落表、独立 tileset、独立 BGM。
- 内容量约为 MVP 的 5–8 倍；需要单独排期与预算。
- 多地图不改变手动战斗、强化失败降级、离线 8 小时、任务只引导不锁通道等核心规则。

#### F.4 与 MVP 的边界

- MVP 只做营地 + 幽暗林地；附录 F 的地图、材料、Boss、美术、音频均不在本次范围。
- MVP 的 `map_id`、`spawn_point_id`、`loot_table_id` 字段为多地图预留，但不实现地区切换。
- 最终版的通道图、地区材料、地图 Boss 需要单独需求评审，不在本文档的验收范围内。
