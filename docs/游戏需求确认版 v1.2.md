## 游戏需求确认版 v1.2（冻结）

**一句话定位：**  
一款PC单机、面向学生党和打工党的“无双割草 + 刷材料做装备”小游戏。单局约3分钟，支持在线自动战斗挂机和离线收益（最多累计8小时），随时退出不丢进度。核心爽点是割草、掉材料、变强、打Boss、出极品装备。

### 已确认需求
| 项目 | 确认内容 |
|---|---|
| 平台 | PC |
| 人数 | 单机 |
| 目标玩家 | 学生党、打工党 |
| 核心情绪 | 爽感、痛快 |
| 参考 | 《传奇》式刷怪爆装成长感 |
| 单局时长 | 约3分钟 |
| 挂机 | 在线自动战斗挂机 + 离线收益 |
| 离线收益上限 | 最多累计8小时 |
| 退出 | 任何时候可退出，进度保存 |
| 地图 | 1张 |
| 怪物 | 3种 |
| Boss | 1个 |
| 装备成长线 | 2条：升级线 + 制作线 |
| 商业化 | 第一版不做 |

### 核心循环
**打怪 → 掉材料 → 升级装备/制作新装备 → 变强 → 继续割草/打Boss → 追求极品装备。**

### MVP范围
- 1张地图、3种怪物、1个Boss
- 材料掉落系统
- 装备系统
- 装备升级线：消耗材料提升已有装备
- 装备制作线：消耗材料制作新装备
- 在线自动战斗挂机
- 离线收益：按时间累积基础材料，最多8小时，上线领取
- 退出保存进度
- 至少1件极品装备作为追求目标

### 离线收益规则（锁定）
1. 离线按时间累积**基础材料**；
2. 最多累计**8小时**；
3. 不产出Boss稀有材料，不直接产出极品装备；
4. 上线后结算并一键领取；
5. Boss和极品装备仍需主动挑战/制作。

### 明确不做
- 联机、交易、组队
- 复杂剧情
- 多地图
- 商业化系统
- 复杂社交
- 大量怪物和装备
- 离线直接送Boss材料和极品装备

### 验收清单
1. 启动进入1张地图并刷怪；
2. 3种怪物形成无双割草感；
3. 击杀掉材料；
4. 材料可用于装备升级线；
5. 材料可用于装备制作线；
6. 装备提升后打怪效率明显感知；
7. 3分钟内体验“刷怪→掉材料→变强”正反馈；
8. 可挑战1个Boss并掉落稀有材料/极品装备；
9. 在线自动战斗挂机可运行；
10. 退出后进度保存，再进入可继续；
11. 离线收益按时间结算、最多8小时、上线可领取；
12. 离线收益不跳过Boss和极品装备追求。
